# ADR-0010 — The image is published at `ghcr.io/scottcochran/tla-kit`, public, from a tag

**Status:** Accepted · 2026.11.16
**Chosen by:** the custodian (`PLAN.md` D3), on 2026.11.16, as the plan recommended.
**State:** Planned, Phase 1. Nothing has been published, and no GitHub Actions run has been tried.
**Depends on:** ADR-0002, ADR-0011 (a licence before publishing).
**Relates to:** ADR-0005 (the release that keeps the tarball), ADR-0014 (releases, and its item 5).
**Pending:** none.

---

## Context

A project cites the image by digest, so the digest has to resolve for anyone who reads the citation: a CI
runner, a reviewer, and a reader of a results file years later. The repository and the projects it serves are on
GitHub.

## Decision

1. **The registry is the GitHub Container Registry,** at `ghcr.io/scottcochran/tla-kit`.
2. **The image is public,** so it can be pulled without credentials.
3. **A workflow publishes on a tag.** It builds the image, runs the self-test (ADR-0002), pushes, and records the
   digest in the GitHub release for that tag. That release links to the one that keeps its prover tarball
   (ADR-0005 item 2, ADR-0014 item 3).
4. **Tags are for people, digests are for citation.** A project's CI and its results name `@sha256:…`. A version
   tag may be added for readability and never replaces the digest.
5. **Published images are never deleted,** whether or not a project's pin names them today (ADR-0014 item 5).

## Consequences

- A public runner pulls the image with no secret, and the projects' CI needs no credentials for it.
- The registry and the code are under one account and one set of permissions.
- tla-kit takes on keeping old digests available. Item 5 is a promise, and the registry's retention settings have
  to keep it.
- A public image redistributes everything inside it. `PLAN.md` D7 settled that it may, on the three conditions of
  `derived/tla-kit-licence-check-2026.11.15.md`. The image has carried its notices since Phase 1a. The other two
  conditions come before the first publish: the copyleft parts' source in the release, and the GMP release and
  `libsha1`'s licence settled.

## Alternatives not taken

- **Docker Hub.** It limits anonymous pulls, and it refused the session's pull of the base image (HTTP 429). It
  would also put the image under a second account, apart from the code.
- **A private image.** Every consumer's CI would need a token, and a cited digest would not resolve for an
  outside reader.
- **Publish on every push to `main`.** The digest would change with every unrelated commit. A tag makes a new
  image a decision.
