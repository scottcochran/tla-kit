# ADR-0011 — This repository is licensed Apache-2.0

**Status:** Proposed · 2026.11.15
**Chosen by:** owed. `PLAN.md` D4, where the recommendation is the one recorded here. It blocks publishing.
**State:** Planned. The repository has no licence.
**Depends on:** nothing.
**Relates to:** ADR-0005 (the bundled tools' licences), ADR-0007 (vendored scripts), ADR-0009 (borrowed
design), ADR-0010 (publishing).
**Pending:** the custodian's decision on D4.

---

## Context

Without a licence, nobody else may use or redistribute the repository's code, and a public image built from it
cannot be offered for use. TOPAK's code is under Apache-2.0. The image also carries tools under their own
licences, and will carry scripts vendored from TOPAK.

## Decision

1. **The code in this repository is under Apache-2.0,** as TOPAK's code is. That covers the `Dockerfile`, `bin/`,
   the spike scripts, the server, and the tests.
2. **The tools in the image keep their own licences.** The image carries a notice that lists each one: TLA+ tools,
   TLAPS, Isabelle, Poly/ML, Z3, Zenon, LS4, and any added later. That list is the outcome of ADR-0005's licence
   check.
3. **Vendored scripts keep the licence they have in TOPAK,** with their source commit recorded (ADR-0007).
4. **The design borrowed from `marco6/tlapm-mcp` is credited.** No code is copied (ADR-0009).

## Consequences

- tla-kit, TOPAK and the skill share one licence, and the vendored scripts move between them without a question.
- Apache-2.0's patent grant and its `NOTICE` convention suit item 2's list of bundled tools.
- The licence does not settle whether the bundled tools may be redistributed. ADR-0005's check does.

## Alternatives not taken

- **MIT.** It is shorter, and `marco6/tlapm-mcp` uses it. But it differs from TOPAK's licence, and it has no patent
  grant.
- **No licence until the server exists.** That blocks a public image (ADR-0010) and Phase 2's use of it by the
  projects.
