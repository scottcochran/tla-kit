# ADR-0011 — Code is licensed Apache-2.0 and documentation CC BY 4.0, as in TOPAK

**Status:** Proposed · 2026.11.15
**Chosen by:** the custodian, 2026.11.15, who directed that `LICENSE`, `LICENSE-DOCS` and a `NOTICE` based on
TOPAK's be added. That settles `PLAN.md` D4.
**State:** Built. `LICENSE` (Apache-2.0), `LICENSE-DOCS` (CC BY 4.0) and `NOTICE` are in the repository. The
image's notice of bundled tools (item 3) waits on ADR-0005's licence check.
**Depends on:** nothing.
**Relates to:** ADR-0005 (the bundled tools' licences), ADR-0007 (vendored scripts), ADR-0009 (borrowed
design), ADR-0010 (publishing).
**Pending:** the custodian's acceptance.

---

## Context

Without a licence, nobody else may use or redistribute the repository's content, and a public image built from
it cannot be offered for use. TOPAK is dual-licensed by content type: code, specifications, policies and tooling
under Apache-2.0, and documentation, decision records and result transcripts under CC BY 4.0. Much of tla-kit
is prose of the same kinds: the plan, these records, and the session record with its annex. The image also
carries tools under their own licences, and will carry scripts vendored from TOPAK.

## Decision

1. **Code is under Apache-2.0** (`LICENSE`), as TOPAK's code is. That covers the `Dockerfile`, `.dockerignore`,
   `bin/`, the spike scripts, and, when they exist, the server, its tests and CI workflows.
2. **Documentation is under CC BY 4.0** (`LICENSE-DOCS`), as TOPAK's documentation is. That covers Markdown
   prose, `PLAN.md`, these records, and `derived/`, including the run transcripts in its annexes.
3. **`NOTICE` draws the line between the two by content type,** after TOPAK's. Shell examples inside a Markdown
   file go with the file.
4. **The tools in the image keep their own licences.** The image carries a notice that lists each one: TLA+ tools,
   TLAPS, Isabelle, Poly/ML, Z3, Zenon, LS4, and any added later. That list is the outcome of ADR-0005's licence
   check. The repository's `NOTICE` says only that they are not part of it.
5. **Vendored scripts keep the licence they have in TOPAK,** with their source commit recorded (ADR-0007).
6. **The design borrowed from `marco6/tlapm-mcp` is credited.** No code is copied (ADR-0009).

## Consequences

- tla-kit, TOPAK and the skill share their licences, so vendored scripts and cited records move between them
  without a question.
- Apache-2.0's patent grant and its `NOTICE` convention suit item 4's list of bundled tools.
- A file's licence follows from its kind, so a new file needs no header to say which one applies.
- The licences do not settle whether the bundled tools may be redistributed. ADR-0005's check does.

## Alternatives not taken

- **MIT for the code.** It is shorter, and `marco6/tlapm-mcp` uses it. But it differs from TOPAK's licence, and it
  has no patent grant.
- **Apache-2.0 for everything.** One licence and no line to draw. But it differs from TOPAK's documentation
  licence, and it is written for software, not prose.
- **No licence until the server exists.** That blocks a public image (ADR-0010) and Phase 2's use of it by the
  projects.
